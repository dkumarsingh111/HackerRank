HAAI++ Capstone HPPCS01 - Execution Instructions

1. cd Codebase
2. python -m pip install -r requirements.txt
3. ollama pull gemma3:1b
4. ollama pull llama3.2:1b
5. ollama serve
6. python main.py --gemma-model gemma3:1b --llama-model llama3.2:1b

Outputs:
- Up to 10 final CV DOCX files
- Up to 10 structured JSON files
- Up to 10 review JSON files
- Source-text and plain-text CV artifacts
- evaluation_summary.json

Optional:
- Add --jd-file job_description.txt to tailor CVs against a target role
- PDF CVs are generated automatically when LibreOffice is installed
